# Accessibility smoke check

Date: 2026-09-03

The public homepage was reviewed in the browser at the Carlcare-inspired upgrade preview URL. The browser exposed labeled, keyboard-reachable anchors for the brand/home link, Book a repair, Repair status, Spare parts, Owner portal, phone call, Start a repair, the service-control cards, the three service routes, footer routes and the direct status/repair calls to action. Visible wording makes the primary actions understandable without relying on icon-only controls.

The page has a visible focus treatment when keyboard navigation begins, and the route structure gives customers multiple non-pointer paths to book, check status or request parts. The public design uses a dark navy/indigo background with bright cyan, blue, emerald and violet accents; the primary text is light on dark surfaces and the primary cyan action has dark text for readable contrast. The mobile menu is a labeled control in the shared shell, and the owner route remains separated from public service actions.

Follow-up: perform a manual screen-reader pass after the owner provides production data and any custom imagery. No blocking keyboard, labeling or contrast issue was observed in this smoke check.
